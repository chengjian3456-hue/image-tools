# ImageTools 每日自动化运营任务设置指南

## 任务目标
每天上午10:00自动执行网站运营任务，包括：
- ✅ 检查网站可访问性
- ✅ 拉取最新代码
- ✅ 生成SEO报告
- ✅ 监控网站状态
- ✅ 每周一自动生成新博客文章

## 方法1：使用Windows任务计划程序（推荐）

### 步骤1：打开任务计划程序
1. 按 `Win + R`
2. 输入 `taskschd.msc`
3. 回车打开"任务计划程序"

### 步骤2：创建基本任务
1. 右侧点击 **"创建基本任务"**
2. **名称**：`ImageTools每日SEO运营`
3. **描述**：`每天10点自动检查网站状态并执行SEO任务`
4. 点击"下一步"

### 步骤3：设置触发器
1. **希望该任务何时开始？** 选择 **"每天"**
2. 点击"下一步"
3. **开始时间**：设置为 `10:00:00`
4. **每隔**：`1` 天
5. 点击"下一步"

### 步骤4：设置操作
1. **希望执行什么操作？** 选择 **"启动程序"**
2. 点击"下一步"
3. **程序或脚本**：浏览选择 `C:\Program Files\Git\bin\bash.exe`
   - 如果Git安装在其他路径，请相应调整
4. **添加参数**：`/c/Users/86159/Documents/image-tools-fix/scripts/daily-seo-operations.sh`
5. **起始于**：`C:\Users\86159\Documents\image-tools-fix\scripts`
6. 点击"下一步"

### 步骤5：完成设置
1. 勾选 **"当单击"完成"时，打开此任务属性的对话框"**
2. 点击"完成"
3. 在属性对话框中：
   - **常规** 选项卡：勾选 **"不管用户是否登录都要运行"**
   - **常规** 选项卡：勾选 **"使用最高权限运行"**
   - **条件** 选项卡：取消勾选 **"只有在计算机使用交流电源时才启动此任务"**（如果是笔记本）
4. 点击"确定"

## 注意事项

1. **Git凭证**：确保Git已经保存了凭证，否则pull会失败
2. **网络连接**：任务运行时需要网络连接
3. **权限**：确保任务计划程序有权限执行脚本
4. **路径**：确认所有文件路径都是正确的

---

## 故障排查

### 如果任务没有运行
1. 打开任务计划程序
2. 找到任务 -> 右键 -> **"属性"**
3. 查看 **"上次运行结果"**
4. 常见错误代码：
   - `0x41301` - 任务正在运行
   - `0x41303` - 任务未运行
   - `0x8004131F` - 权限问题

### 查看详细日志
1. 任务计划程序 -> 右侧 **"启用所有任务历史记录"**
2. 查看具体错误信息
